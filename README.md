# 🎮 Dokimon Russificator / Русификатор Dokimon

Полный русский перевод игры [Dokimon: Quest](https://store.steampowered.com/app/2019300/Dokimon/) для Steam-версии.

![скриншот](screenshots/dialogue.png)

## ✨ Что переведено

- Весь игровой текст: диалоги NPC, сюжет, реплики тренеров, квесты
- Названия и описания всех 140+ монстров
- Предметы, приёмы, интерфейс, туториалы, магазин
- Имена персонажей в катсценах (Рэй, Аки, Майко, Ксе…)
- Реплики монстров («Няяя», «Вака вака!»)
- **Кириллица добавлена во все шрифты игры**, включая HD-шрифт

## 📦 Установка

1. Скачайте **[Dokimon_Russificator.zip из раздела Releases](../../releases)**
2. Запустите **`install.exe`**
3. Игра найдётся автоматически — или укажите `Dokimon.exe` через «Обзор...»
   (можно просто перетащить exe на `install.exe`)
4. Нажмите «Установить русификатор» и запускайте игру

<details>
<summary><b>Тихая установка (для гиков)</b></summary>

```
install.exe "J:\SteamLibrary\steamapps\common\Dokimon\Dokimon.exe"
```
</details>

## 🔄 Автозапуск через Steam (по желанию)

Steam → ПКМ по Dokimon → Свойства → Параметры запуска:

```
"<путь к папке>\PLAY_RU.cmd" %command%
```

Игра всегда стартует на русском, а после выхода оригинальный `data.win`
автоматически восстанавливается — Steam ничего не замечает.

## ❓ FAQ

**Игра обновилась, русский пропал?**
Запустите `install.exe` ещё раз (или `UPDATE_RU.cmd` после выхода из игры).

**Как вернуть английский?**
`Restore_Original.cmd` или проверка файлов в Steam.

**В HD-режиме другой шрифт?**
Для русского языка диалоги всегда рисуются пиксельным шрифтом —
вертикальная раскладка HD-шрифта не рассчитана на русские переносы.

**Клички моих монстров остались латиницей?**
Клички хранятся в сохранении — их можно сменить в игре.

## ⚙️ Как это устроено

- В шрифты `fn_yana`, `fn_yana5x5`, `fn_yanaTINY`, `fn_YuGothic`
  добавлены кириллические глифы (ark-pixel 10px, Tiny5, Yu Gothic)
- Перевод лежит в `Localization/french/*.txt` (слот французского)
- Патч кода: пункт «Русский» в меню, автовыбор по языку Steam,
  отключение французских смещений текста
- `install.exe` ничего не ломает: оригинал хранится в `data.win.original`
